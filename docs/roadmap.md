## 3. 阶段 1：记忆图存储与检索内核（M1）

**交付物**

1. `GraphStore` 端口 + FalkorDB 适配器（保留 Neo4j 备选）；批量摄入基准脚本。
2. 向量索引端口（原生 HNSW 优先；不达标时 FAISS/HNSW，索引更新可恢复）。
3. 情景写入（只增不改）、撤回标记、共激活事件（`pairId+batchId` 幂等）。
4. 语义路径 + Hebbian 扩散路径；来源标记；合并去重；Top-K ≤ 50。
5. `memory-graph.episode.retrieve.v1` 与 `retrieval.read.v1`；管理端受限图查询。
6. 检索审计记录：预算、两路候选、来源、耗时、降级标记。

**验收门槛**

- 双路径 Recall@20 ≥ 单语义路径 + 10pp（合成对话数据集）。
- 10 万节点检索 P95 ≤ 300ms。
- 共激活事件重复投递不产生重复边权增量。
- 批量摄入吞吐量有报告，作为图引擎最终选型依据（计划 6.3）。

**当前进度（2026-11-11）**：`memory-graph` 的内存纵向切片已完成并通过 31 个模块测试——占位 501 已替换为写入/读取/撤回、语义 + 扩散检索、审计、共激活事件、结构化图查询、强化/遗忘与批次幂等。FalkorDB 适配、BGE-M3/HNSW、概念节点、枢纽蒸馏、批量摄入与三条量化门槛仍未完成，M1 不能标记完成。证据见 [phase1-memory-graph.md](phase1-memory-graph.md)。

**风险/阻塞**：本机无 Docker → 真实 FalkorDB 集成与压测未验证；需先准备环境。

## 4. 阶段 2：编排器与 System-One 控制平面（M2）

**交付物**

1. System-One 门控（规则 + 可替换轻量分类器），决策 ≤ 15ms，命中率可配置/可监控。
2. 检索预算参数化；Top-20 → Top-5 轻量重排序（不调用大模型逐条筛选）。
3. 提示组装（人格快照 + 记忆 + 工作记忆 + 降级提示）。
4. SSE 回合接口：`turn.started` → `token` → `turn.completed` / `turn.degraded` / `error`。
5. 回合审计：门控决策、预算、候选、重排、最终提示引用。
6. `turn.processed` / `turn.degraded` 事件；记忆/人格不可用时的降级路径。

**当前进度（2026-11-13）**：最小 Demo 已实现 SSE 回合、记忆检索/写入、persona 快照注入（身份层 + 适应层）、模板回复与 LLM 配置保存；真实 System-One 分类器、重排、真实 token 流与量化门槛未完成。见 [demo-minimal.md](demo-minimal.md)。

**验收门槛**

- 慢路径 P50 ≤ 1.2s、P95 ≤ 2.5s；快路径 P50 ≤ 400ms。
- 门控命中率在开发集可调、可观测；决策耗时 ≤ 15ms。
- 重排后 Top-5 人工相关性 ≥ 4/5。
- memory-graph 不可用时回合仍完成，`memoryDegraded` 正确传到前端；persona-state 不可用时只用只读快照且拒绝写人格动作。

## 5. 阶段 3：人格双层治理与异步巩固（M3）

**交付物**

1. 身份层版本化 CRUD + 回滚；身份层禁止自动写入。
2. 适应层有界更新（`adaptation_step_max`，超出截断 + 告警）。
3. 经历日志只追加、可完整回放。
4. 巩固作业队列：持久化、幂等（`jobId+idempotencyKey`）、有限重试、死信、可重放、单作业超时。
5. proposal 队列：同方向 `N_consistency` 次 + 累计幅度 ≥ `identity_change_min` 才创建。
6. 遗忘（新近性 + 连接强度，`T_fade`/`w_min`）与枢纽蒸馏（`hub_degree_min`/`hub_cluster_min`）。
7. 调度器：定时 + 空闲触发，频率上限。

**验收门槛**

- 身份层自动化测试证明“巩固不会直接改写身份层”。
- 适应层单次变化不超上界；经历日志可回放。
- 巩固在回合结束后不阻塞响应；死信可查询/重放。
- 遗忘与蒸馏有参数化测试与可观测指标。

## 6. 阶段 4：前端与端到端加固（M4）

**交付物**

1. `admin-web`：双栏人格编辑器、记忆图可视化（NVL）、检索审计回放、巩固监控、proposal 审批。
2. `conversation-web`：SSE 流式渲染、降级提示、会话管理。
3. 全模块 `/internal/health|ready|metrics` + 关键指标看板/告警（门控命中率、检索 P95、巩固积压、死信数）。
4. 故障注入：图存储不可用/超时、人格不可用、LLM 首 token 超时、巩固持续失败。
5. 接入验收清单全项复核；权限审计与数据范围测试。

**验收门槛**

- 管理端写操作经独立 `*.admin.*` 权限并写审计事件。
- 检索审计可复现任一历史回合的完整决策链。
- 故障注入下降级行为符合矩阵且不绕过授权。
- 端到端延迟满足阶段 2 指标。

## 9. 阶段 0 报告模板

每次阶段汇报固定三段：

1. **已实现**：代码路径 + 测试/命令 + 证据（通过输出摘要）。
2. **仅声明**：契约/占位/文档，明确“无运行时功能”。
3. **未验证**：实现存在但缺环境/数据/权限，列出原因与解除条件。

禁止把“仅声明”或“未验证”合并进“已实现”。
